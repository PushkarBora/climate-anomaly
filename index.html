Climate anomaly indices · ICAR-IASRI, New Delhi

How unusual was this month, for this place?

Climate Anomaly compares every month in your climate record with the normal for that same calendar month at that same place. It reports the departure as RAI, MRAI, SRAI, SSPI and SPI for rainfall, and as z-scores, deviations and percentage departures for rainfall and temperature. You choose the baseline period.

What it computes

Five rainfall indices, three anomaly forms, and the climatology behind them

Rainfall indices

Standardised dry–wet scales

RAIRainfall Anomaly Indexvan Rooy (1965). Scaled by the means of the wettest and driest years.
MRAIModified RAIEkpetere (2025). Uses the record maximum and minimum; bounded at ±3.
SRAIStandardized RAIEkpetere (2025). Brings the standard deviation into the scaling.
SSPISimplified SPIRaziei (2021). Skewness-corrected, no distribution fitting, handles dry months.
SPIStandardized Precipitation IndexMcKee et al. (1993). Gamma fit with zero-rain probability, mapped to a normal score.

Data format

Use one row per location and time step, with each variable in its own column. Column names can be anything; you match them in step 2. Extra columns are ignored.

ItemNeeded?Accepted values
LocationOptionalAny text or code (state, district, station, grid ID). Omit for a single site.
Year or dateYesA four-digit year, e.g. 1998, or a full date: 1998-06-15, 15-06-1998 or 15/06/1998 (day first), Jun 1998, Excel dates. A date column also gives the month.
MonthOnly with a year column1–12, Jan, January. Omit for annual data.
RainfallAt least one variableNumeric total for the time step (mm or any unit)
Tmax, Tmin, TavgAt least one variableNumeric, °C. Each temperature is used only if your file has that column.

One column per location (a "wide" file, common for gridded and district datasets) also works: a date or year/month column, then one column of values per location. In Match Columns, set Location to Each location is a separate column, say which variable the columns hold, and tick the location columns to include.

Daily data is accepted: when a location has several rows in the same month, rainfall is summed and temperatures are averaged before any index is computed. Check that every month is complete, because a month with missing days will have a lower rainfall total.

Missing values: blank cells and NA are always missing. Add your own codes (for example -999) in step 1.

Using the model

The Model page has four tabs. Work through them in order with the Next button at the bottom of each tab, or click a tab to go back and change something.

  1. Upload Data. Drop a file on the upload area or choose it. For an Excel workbook with several sheets, pick the sheet. A preview of the first rows appears. The sample dataset is loaded when the page opens, so you can try the model before using your own file.
  2. Match Columns. Check the location column (or Each location is a separate column), the year or date column, the month column if there is one, and each variable. The summary underneath reports how many location-months were read, how many rows were skipped and whether daily rows were combined.
  3. Baseline Period. Choose the reference years for rainfall and for temperature (see below).
  4. Indices. Tick the indices you need and, if required, open Advanced settings to change the number of RAI extremes, the minimum baseline size or the number of decimals. Press Compute indices.
  5. Results. The results open on their own page. Use the Location, Month and Index filters to explore the chart, the class frequencies, the baseline climatology and the full table.
  6. Download or print. Download results gives one CSV row per location-month with every index and class; Climatology gives the baseline mean, SD and number of years for each location-month; Print report prints the selected location (settings, chart, classes, climatology and table) or saves it as PDF. Use Back to the model to change settings and compute again.

Choosing the baseline period

Every index compares a value with the normal for the same place and calendar month. The baseline is the set of years that defines that normal. All parameters (mean, standard deviation, maximum, minimum, extreme-year means, percentiles and the Gamma fit for SPI) are estimated from the baseline years only, and every year in the record is then scored against them. Values outside the baseline can therefore fall beyond the usual range of an index, for example MRAI above +3.

  • Full record (default): all years in the file.
  • Last N years: the N most recent years, e.g. 20 or 30.
  • First N years: the N earliest years.
  • Custom range: any start and end year. The WMO recommends 30-year normals and currently uses 1991–2020 as the standard reference period (WMO, 2017).

Rainfall and temperature have separate baselines, so you can, for instance, use the full record for rainfall and 1991–2020 for temperature.

Formulas

Notation: P is the rainfall of one place in one calendar month of one year; X is any variable. Bars and s denote the baseline mean and sample standard deviation of the same place and calendar month.

RAI · Rainfall Anomaly Index

van Rooy (1965)
RAI = 3 × P − PM − Pif P ≥ P
RAI = −3 × P − PX − Pif P < P
M, X: mean of the n highest and n lowest baseline values (n = 10 by default, at most half the baseline).

MRAI · Modified Rainfall Anomaly Index

Ekpetere (2025)
MRAI = 3 × P − PPmax − Pif P ≥ P
MRAI = −3 × P − PPmin − Pif P < P
Pmax, Pmin: largest and smallest baseline values.

SRAI · Standardized Rainfall Anomaly Index

Ekpetere (2025)
SRAI = 3 × P − σPmax − σif P ≥ P
SRAI = −3 × P − σPmin − σif P < P
σ: baseline standard deviation. Results are clipped to −3 … +3 unless switched off in Advanced settings.

SSPI · Simplified Standardized Precipitation Index

Raziei (2021)
P* = P1/3 if skewness > 0.5;  P* = P3 if skewness < −0.5;  otherwise P* = P
Δ = P* − P*
SSPI = 3 [ ΔPT − P* + ΔPT − P* · ΔPMX − P* ]if Δ > 0, PZP < 40%
SSPI = −3 [ ΔPB − P* + ΔPB − P* · ΔPMN − P* ]if Δ ≤ 0, PZP < 40%
SSPI = −3 × P* − P*−PMX + εif PZP ≥ 40%
PT, PB: 95th and 5th percentiles of the transformed baseline; PMX, PMN: its maximum and minimum; PZP: percentage of baseline years with zero rainfall; ε = 10−6.

SPI · Standardized Precipitation Index

McKee et al. (1993); Thom (1958)
G(P) = Gamma CDF with shape α and scale β fitted by maximum likelihood to the non-zero baseline values
H(P) = q + (1 − q) G(P)
SPI = Φ−1( H(P) )
q: share of baseline years with zero rainfall; Φ−1: inverse standard normal CDF. With fewer than four non-zero baseline values the z-score is used instead.

Anomalies for rainfall and temperature

Standard definitions
Standardised anomaly (z) = X − Xs
Deviation = X − X
Percentage departure = X − XX × 100
For temperature, the percentage departure is relative to a °C value and is best read as a relative indicator; the deviation in °C is usually easier to interpret.

Classes

Class boundaries include the upper limit, so a value of exactly −1 falls in the class that ends at −1.

RAI, MRAI, SRAIClass
SPI, SSPI, rainfall zClass
Rainfall % departure (IMD)Class
Temperature zClass

Deviation classes (rainfall in data units, temperature in °C) and temperature percentage classes use fixed thresholds, symmetric about zero: rainfall deviation ±20, ±50, ±100; temperature deviation ±0.5, ±1.5, ±3 °C; temperature departure ±0.5, ±2, ±5 %.

Notes and limits

  • Groups with fewer baseline values than the minimum (default 4) are left blank. Thirty years is the usual recommendation for a stable normal.
  • SPI uses the exact maximum-likelihood Gamma fit (starting from Thom's approximation), and results agree with scipy.stats.gamma.fit.
  • Skewness for SSPI is the moment estimator without small-sample correction, as in scipy.stats.skew.
  • Percentage departure is left blank when the baseline mean is zero, for example in a month that never rains.
  • Indices here are computed at the one-month time scale (or annual, for annual data). For 3-, 6- or 12-month SPI, aggregate your rainfall to rolling totals first and upload those.
  • Your file never leaves your computer. Very large files (several hundred thousand rows) may take a few seconds.
